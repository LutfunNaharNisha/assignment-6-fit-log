# 🏋️ FitLog

FitLog is a high-performance dark-themed workout tracking app built to help users search exercises, structure focused daily lift targets, and save workouts.

## 🛠️ Technologies Used

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Asset Optimization:** Next.js `<Image />` component

---

## ✨ Key Features

1. **Exercise Library & Filtering:** Easily search and filter workouts by targeted muscle group, equipment required, and difficulty level.
2. **Cap-of-5 Daily Planner:** Add up to 5 target exercises per day to maintain a focused and achievable daily workout routine.
3. **Real-Time Calorie & Duration Metrics:** Automatically calculate total planned training minutes and estimated calorie burn in real-time.
4. **Saved Lifts Collection:** Bookmark favorite lifts to quickly access or queue them into upcoming plans.
5. **Adaptive Navbar Indicators:** Dynamic badge highlighting in the header navigation that updates based on the active tab view (`Today Plan` vs `Saved`).
